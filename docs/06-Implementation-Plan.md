## Before moving on (بعد كل Milestone)

1. شغّل التطبيق فعليًا (محليًا ثم staging).
2. تحقق من معايير القبول الخاصة بالمرحلة.
3. شغّل اختبارات العزل — **لا تنتقل وأي اختبار عزل فاشل.**
4. سجّل أي مشكلة غير محلولة في قسم «Open questions» في [PRD](01-PRD.md) أو كـ GitHub issue.
5. حدّث الوثائق الست إن تغير أي قرار.
